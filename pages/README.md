# AI 概念視覺化 AI Concept Visualizer

一條「從完全不懂到理解 AI 在做什麼」的分級互動學習路徑。每一頁都不只是把概念畫出來，而是**先讓學習者動手做一次、做到卡住，再告訴他那個卡住的地方叫什麼名字**。

全部是單檔 HTML，無框架、無相依，下載後直接用瀏覽器打開就能在教室使用。

---

## 為誰做

- **高中生與 AI 初學者**：興大附中 GET 團隊的 AI 素養課程、補習班的理科學生
- **使用情境**：課堂上由老師帶著操作，或學生自己在手機、平板、筆電上打開
- **先備知識**：初級完全不需要數學；中級只需要「斜率」的直覺

## 解決什麼問題

我在補習班與 AI 素養課程中觀察到，學生對 AI 的誤解通常不是「不知道某個名詞」，而是腦中有一個**錯誤的心智模型**，例如：

| 常見誤解 | 對應頁面 |
|---|---|
| 「AI 就是人寫了一堆 if-else 規則」 | 從規則到學習 |
| 「模型裡面有一套看得懂的邏輯」 | 神經網路 |
| 「訓練就是讓模型慢慢滑到正確答案」 | 梯度下降 |
| 「修正時資料會倒著流回去」 | 反向傳播 |
| 「我每次跟 AI 聊天，它就學到一點東西」 | 訓練與推論（規劃中） |
| 「AI 錯是因為它還不夠聰明」 | AI 為什麼會錯（規劃中） |

市面上的 AI 視覺化工具多半是給已經懂的人看的示意圖。這個專案反過來：**每一頁先設定一個要拆掉的誤解，再設計一個能讓學生親手推翻它的互動。**

## 設計原則

1. **先體驗，再命名**：術語一定出現在學生已經做過那件事之後。
2. **每個比喻都要經得起追問**：比喻是為了精確，不是為了親切。例如反向傳播用「究責鏈」，因為「責任按被信任的程度往回分配」本身就是連鎖律。
3. **針對誤解，不是針對知識點**：每頁先寫下要拆掉的錯誤心智模型，再決定互動。
4. **可操作才算數**：每頁的挑戰卡是可重現的操作指令，不是說明文字。

## 設計決定舉例

- **梯度下降的球用「跳」不用「滾」**：刻意畫成離散跳躍，避免學生以為參數更新是連續滑動。
- **從規則到學習用 14 張手工設計的貓狗卡**：精準控制五個特徵的組合，讓任何單一規則的正確率都卡在 64%–71%，逼出「規則永遠有例外」的體驗，再改用範例學習（最近鄰分類）對照。
- **中級三頁共用同一個 3→2→1 網路與同一份資料**：學生在已經認識的網路上學新機制，認知負荷留給機制本身。
- **反向傳播切換線條的意義**：前向時粗細代表權重，反向時代表責任大小，並在圖例明確提醒「線的意思換了」，這個切換本身就是教學點。

## 依使用回饋迭代

- 學生情境從「手搖飲試喝」改為「抽卡遊戲鑑定」：更貼近高中生的經驗，而「稀有度／數值／立繪」剛好對應類別、數值、視覺三種不同性質的特徵。只換包裝，網路結構與所有數字都不變。
- 放慢神經網路頁的自動訓練動畫，讓誤差下降的過程看得見，而不是一閃而過。
- 前向傳遞動畫改成分兩段、點一下才播下一段，讓說明文字來得及讀。

## 頁面與進度

| 層級 | 頁面 | 狀態 |
|---|---|---|
| 初級：AI 到底是什麼 | 從規則到學習 `pages/rule_to_learning.html` | ✅ 完成 |
| | 訓練與推論、AI 為什麼會錯 | 規格骨架 |
| 中級：機器是怎麼「學」的 | 神經網路 `pages/neural_network.html` | ✅ 完成 |
| | 梯度下降 `pages/gradient_descent.html` | ✅ 完成 |
| | 反向傳播 `pages/backpropagation.html` | ✅ 完成 |
| 高級：現代 AI 的引擎室 | 注意力機制、擴散模型、不只有神經網路 | 規格骨架 |

骨架頁面已包含設計系統、術語辭典與規格說明（要拆的誤解、要產生的理解、預定互動），可以直接接手開發。完整的設計紀錄見 [`docs/roadmap.md`](docs/roadmap.md)。

## 怎麼使用

1. 下載或 clone 這個 repo
2. 用瀏覽器打開 `index.html`，從學習地圖選一頁開始
3. 不需要安裝任何東西，也不需要網路（字型除外）

## 技術

- 純 HTML / CSS / JavaScript，每頁單一檔案
- 全站共用設計系統：深淺色主題、術語彈出視窗、生活化比喻標籤
- 以 AI 程式助理輔助開發；教學設計、互動設計與取捨由作者決定
